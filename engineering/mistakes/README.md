# Mistakes

This directory records lessons learned from real development incidents.

Each note explains what happened, why it happened, and how to prevent it from happening again.

## Checklist

This checklist summarises reusable lessons from the mistake notes in this directory.  
Update it whenever a new mistake identifies a check that should be performed in future.

<Describe what happened factually and concisely.>

<Explain the root cause rather than the immediate symptom.>

- <Lesson 1>
- <Lesson 2>
- <Lesson 3>

<List the concrete actions or checks that help prevent the same mistake from happening again.>
